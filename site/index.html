Free and open source

Your HTML animation, as a real MP4.

TockMux takes a web page that moves by itself and records it frame by frame, on a clock it controls. The video comes out smooth, the exact size you asked for, and the same on every computer. No screen recorder, no dropped frames.

npm install -g tockmux

Needs Node.js 18 or newer. Then run tockmux setup once. Version 4.0.0 is live on npm.

Privacy and safety

Your files stay yours.

TockMux renders on your computer. It does not upload your pages, your videos or your analytics anywhere.

Local by default

Rendering, checking and watching happen on your machine. No account is needed.

Studio and MCP stay in your folder

The Studio listens only on 127.0.0.1 and rejects other host names. The MCP server cannot read or write outside the folder you start it in.

Your keys, your file

ElevenLabs keys are kept in ~/.tockmux/voice.json with owner-only permissions, never in your project.

The problem

A web page is not a video.

An AI tool can write a beautiful animated page in a minute. But you cannot post that page to TikTok, drop it into a slide deck, or send it to a client who expects an MP4. The usual fix is a screen recording, and it breaks in four ways.

01

It stutters

The browser moves on the wall clock. If the computer is busy for a moment, the recorder keeps whatever was on screen.

02

It changes

Two recordings of the same page are never identical, so you cannot repeat a good take.

03

It is the wrong size

The result depends on your window, your screen and your zoom level.

04

The voice is out of sync

You export a silent video and then line up the narration by hand in an editor.

How it works

Take control of time.

A page can only look different from run to run because it reads the clock. TockMux replaces every clock the page can see before the page loads. Time then moves only when TockMux says so.

1

Replace the clock

Timers, animation frames, Date, performance.now(), CSS animations and Math.random (seeded) all wait for TockMux.

2

Advance one frame

For every frame, the clock moves by exactly 1/30 of a second and the page reacts in order.

3

Capture and encode

TockMux takes the picture through the browser's debugging protocol and pipes it into FFmpeg. Long videos render in parallel and are joined without re-encoding.

The result: a slow computer takes longer, but the frames are the same. The test suite checks this to the pixel.

Features

Everything you need, nothing you do not.

Bring the HTML you have

Plain CSS, requestAnimationFrame, GSAP, anime.js, Lottie, canvas and SVG render as they are. No framework to adopt.

Voice-over that fits

--auto-fit stretches the animation itself to the length of your narration. Music can loop, fade and duck under speech.

Watch mode

tockmux watch re-renders the video every time you save the file, so you see each change in seconds.

Check before you wait

tockmux check opens the page and tells you whether it will be a still image, cropped, or missing an image, before a long render starts.

Batch a whole folder

tockmux batch ./slides --out-dir ./videos renders 40 scenes while you make coffee.

Studio, drag and drop

tockmux studio opens a small app in your browser with live preview, progress and a download button.

A tiny language for titles

Write a short .tmx script for a film made of titles, counters and bars, with themes and transitions, and no HTML at all.

Plain-English errors

Every problem comes with a line number and a fix. tockmux doctor checks your setup and says exactly what to install.

For AI assistants

Let your assistant make the video.

TockMux includes a Model Context Protocol (MCP) server. Claude Desktop, Claude Code, Cursor and other assistants can check a page, preview a frame as an image and render the final MP4, while you watch.

The assistant can only read and write inside the folder you start it in.

# Claude Code
claude mcp add tockmux -- npx -y tockmux mcp

# Claude Desktop or Cursor: print the JSON config
tockmux mcp --print-config
For developers

Use it as a library.

The same engine that powers the command line is one import away, so your build scripts and apps can render videos too.

import { convert } from "tockmux";

const result = await convert({
  input: "promo.html",
  flags: { output: "promo.mp4", preset: "tiktok" }
});
console.log(result.output, result.durationSec);

How to use it

A short guide.

Five steps from an HTML file to a finished video. Every command has --help.

1

Install and set up

npm install -g tockmux
tockmux setup
tockmux doctor

setup downloads a browser once. doctor checks everything and tells you what is missing.

2

Make a video

tockmux render my.html
tockmux render my.html --preset tiktok
tockmux render my.html --format gif

Sizes: youtube, tiktok, square, portrait, cinema, 4k. Run tockmux presets for all of them.

3

Check and iterate

tockmux check my.html
tockmux watch my.html

check warns about problems before a long render. watch re-renders every time you save.

4

Add a voice-over

tockmux render my.html --voice narration.mp3 --auto-fit
tockmux voice add --name main

--auto-fit stretches the animation to the narration. ElevenLabs keys stay on your computer.

5

Use it your way

tockmux studio
tockmux batch ./slides --out-dir ./videos
tockmux mcp --print-config

Studio is a drag-and-drop app. Batch renders a folder. MCP lets an AI assistant make videos for you.

Your first HTML page

TockMux works with any page that moves by itself. Start with this, save it as my.html, and render it:

<!doctype html>
<html>
<head>
  <meta name="html2mp4:duration" content="6">
  <style>
    body { margin: 0; background: #F4EFE3; }
    .box { width: 200px; height: 200px; background: #E3B95C; border: 6px solid #161514;
           position: absolute; top: 400px; left: 0;
           animation: move 6s linear infinite; }
    @keyframes move { to { left: 1520px; } }
  </style>
</head>
<body><div class="box"></div></body>
</html>

Run tockmux render my.html. You get a six-second MP4 with the square sliding across the screen.

Use it from code

import { convert } from "tockmux";

const result = await convert({
  input: "my.html",
  flags: { output: "my.mp4", preset: "tiktok" }
});
console.log(result.output, result.durationSec);

Troubleshooting

"No browser found"

Run tockmux setup, or install Chrome or Edge.

The video is a still image

The page does not move by itself. Run tockmux check to see why.

The page waits for a click

Add --start "#your-button".

Anything else

Run again with --debug and send the output to Spidey_Moon on Discord.

Every command and option is in the package: run tockmux help, or see the package page on npm.

FAQ

Good questions.

Can every HTML file become an MP4?

Any page that plays by itself over time. Pages that wait for a click, a keypress or a login cannot be recorded without a person. TockMux checks this for you with tockmux check.

Does it need the internet?

Rendering runs on your computer. Only the ElevenLabs narration feature (optional) talks to an online service, using keys you own.

Is it safe to run other people's HTML?

Treat it like opening the file in a browser. Studio only listens on your own computer. If you ever host TockMux as a public service, run each job in an isolated container, because this package does not do that for you.

Is it free?

Yes. TockMux is MIT licensed. You need Node.js and a Chromium-based browser, which tockmux setup can download.

Windows, macOS, Linux?

All three are supported by the code. Windows is the platform the author uses daily; please report anything odd in an issue or on Discord.
