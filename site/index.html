Your HTML animation, as a real MP4.

TockMux takes a page that moves by itself and records it frame by frame, on a clock it controls. The video is smooth, the exact size you asked for, and identical on every computer. No screen recording, no dropped frames.

$npm install -g tockmux

Needs Node.js 20 or newer. Then run tockmux setup once to get the browser.

How it works

Take control of time.

A page only looks different from run to run because it reads the clock. TockMux replaces every clock the page can see before it loads. Time moves only when TockMux says so.

01

Replace the clock

Timers, animation frames, Date, performance.now(), CSS animations and Math.random all wait for TockMux.

02

Advance one frame

For each frame, the clock moves by exactly 1/30 of a second and the page reacts in order.

03

Capture and encode

Each picture goes to FFmpeg. Long videos render in parallel and join without re-encoding.

What you can make

Files, lengths and limits.

TockMux is precise about what it accepts, so you know before you start.

FileWhat it is forNotes
.html, .htmA page that moves by itselfThe main input. CSS, JavaScript, canvas, SVG, GSAP and Lottie all work.
.tmxA title film written as a scriptNo HTML needed.
.mp4An existing video, for syncAdd a voice-over or music to it.
.mp3 and other audioVoice-over or musicMP3 is the format that is tested.

Anything else, such as .txt, .pdf, .docx, or a lone .png or .jpg, is refused. Images and fonts a page uses are fine.

⏱️

How long

Up to one hour. Without a length, the video is 10 seconds. Set it with --duration 20 or a meta tag.

🕒

Render time

A 30-second 1280×720 film takes about 40 to 50 seconds on a normal computer.

🎞️

MP4, GIF, WebM

MP4 has sound and is the default. GIF is for loops and readmes. WebM is for web embeds.

📐

Sizes

YouTube 1920×1080, HD 1280×720, TikTok 1080×1920, square, portrait, cinema at 60 fps, and 4K.

🚫

What it cannot record

Pages that need a click, typing or a login during the video (a single click at the start works with --start). Sound the page plays itself (use --voice or --music). Protected embeds such as YouTube or Netflix.

✅

If your page already moves

Record it for exactly the time you want.

tockmux render landing.html --duration 20

If your page is static

A static page renders as a still image. Describe the look you want with /tockmux:make, and Claude writes an animated page to match.

/tockmux:make a 20-second promo, warm colours, --duration 20

Not sure if your page moves? Run tockmux check landing.html first.

For AI assistants

Let your assistant make the video.

TockMux includes an MCP server, so Claude Desktop, Claude Code, Cursor and other assistants can check a page, preview a frame and render the MP4, while you watch.

It can only read and write inside the folder you start it in.

# Claude Code: add the MCP server
claude mcp add tockmux -- npx -y tockmux mcp

# Claude Code plugin: /tockmux commands
/plugin marketplace add Anand2k29/TockMux
/plugin install tockmux@tockmux
For developers

Use it as a library.

The engine behind the command line is one import away, so build scripts and apps can render videos too.

import { convert } from "tockmux";

const result = await convert({
  input: "promo.html",
  flags: { output: "promo.mp4", preset: "tiktok" }
});
console.log(result.output, result.durationSec);
FAQ

Good questions.

Can every HTML file become an MP4?

Any page that plays by itself over time. Pages that wait for a click, a keypress or a login cannot be recorded without a person. tockmux check tells you which kind yours is.

Does it need the internet?

Rendering runs on your computer. Only the optional ElevenLabs narration talks to an online service, using keys you own.

Is it safe to run other people's HTML?

Treat it like opening the file in a browser. Studio listens only on your own computer. If you host TockMux as a public service, run each job in an isolated container.

Is it free?

Yes. TockMux is MIT licensed. You need Node.js and a Chromium-based browser, which tockmux setup can download.

Windows, macOS, Linux?

Windows is tested on every change. macOS testing is in progress, and Linux has not been tested yet. Help with either is welcome: see CONTRIBUTING.md.
